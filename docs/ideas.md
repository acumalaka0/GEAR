<h2 style="color: #ff0055; border-bottom: 2px solid #ff0055; padding-bottom: 8px; text-shadow: 0 0 5px #ff0055;">
  1. Produk "Umpan" Murah/Gratis (Keterlibatan / Engagement)
</h2>

<p style="color: #d1d1d1;">Saat ini harga minimum adalah <span style="color: #ff0055; font-weight: bold;">1⭐ (Nick Pack)</span>. Diperlukan pintu masuk yang murah atau gratis bagi pemain baru.</p>

* <strong style="color: #ffffff;">"Warna Hari Ini" / Kode Livery Gratis</strong> — Gratis sekali sehari (meningkatkan retensi dan login harian).
* <strong style="color: #ffffff;">Paket Livery Dasar untuk Model Teratas</strong> (R34, Supra, M5, Lambo) — <span style="color: #ff0055; font-weight: bold;">5–15⭐</span>. Produk paling laris di media sosial; saat ini hanya ada satu contoh stiker vinyl di pasar.
* <strong style="color: #ffffff;">Paket Starter untuk Pemula</strong> (garasi + suara + plat nomor) dengan diskon khusus.

<hr style="border: 0; height: 1px; background: linear-gradient(to right, #ff0055, transparent); margin: 25px 0;">

<h2 style="color: #ff0055; border-bottom: 2px solid #ff0055; padding-bottom: 8px; text-shadow: 0 0 5px #ff0055;">
  2. Kategori Produk Baru di Pasar (Marketplace)
</h2>

* <strong style="color: #ffffff;">Preset Suspensi / Drift</strong> (sudut, kerendahan/lowering, kekakuan) — terpisah dari kotak roda gigi (gearbox).
* <strong style="color: #ffffff;">Suara Mesin / Knalpot</strong> (turbo, V8 burble) — permintaan tinggi dari komunitas.
* <strong style="color: #ffffff;">Plat Nomor / Emblem</strong> (papan kustom).
* <strong style="color: #ffffff;">Livery Kendaraan Khusus</strong>: Polisi, taksi, ambulans — mendukung mode yang ada di dalam game.
* <strong style="color: #ffffff;">Asap Drift, Neon, Cahaya Lampu Depan</strong> (preset warna kustom).
* <strong style="color: #ffffff;">Stiker / Dekal</strong> terpisah dari balut bodi penuh (paket stiker).
* <strong style="color: #ffffff;">Build Karakter Jadi</strong> (pakaian / animasi / emoji).

<hr style="border: 0; height: 1px; background: linear-gradient(to right, #ff0055, transparent); margin: 25px 0;">

<h2 style="color: #ff0055; border-bottom: 2px solid #ff0055; padding-bottom: 8px; text-shadow: 0 0 5px #ff0055;">
  3. Fitur & Alat (Tools)
</h2>

* <strong style="color: #ffffff;">Pustaka Kode Siap Pakai per Model Mobil</strong> — fitur pencarian/filter <em>"pilih mobil Anda → livery siap pakai untuk mobil tersebut"</em> (saat ini hanya ada generator warna dari nol).
* <strong style="color: #ffffff;">Peringkat / Pemungutan Suara Preset</strong> — daftar teratas <em>"setelan terbaik untuk X"</em>.
* <strong style="color: #ffffff;">Kalkulator Suspensi</strong> (sudut camber, lowering) — terintegrasi dengan kalkulator gearbox.
* <strong style="color: #ffffff;">Perbandingan Mobil / Spesifikasi</strong> — tabel perbandingan akselerasi dan kecepatan maksimum.
* <strong style="color: #ffffff;">Wishlist / Favorit</strong> — menyimpan preset yang disukai untuk dibeli nanti.
* <strong style="color: #ffffff;">Program Referral</strong> — mendapatkan Bintang (stars) untuk setiap teman yang diundang (fitur viralitas).
* <strong style="color: #ffffff;">Bonus Bintang Harian / Sistem Streak</strong> — gamifikasi untuk mendorong login setiap hari.
* <strong style="color: #ffffff;">Notifikasi Preset Baru</strong> — berdasarkan langganan atau model favorit.
* <strong style="color: #ffffff;">Integrasi dengan Panduan</strong> — tautan langsung ke TikTok/YouTube dari kartu produk.
* <strong style="color: #ffffff;">Dukungan Multi-bahasa</strong> — menjangkau audiens internasional (ID, MY, TR, TL); antarmuka bahasa Rusia membatasi jangkauan pasar.

<hr style="border: 0; height: 1px; background: linear-gradient(to right, #ff0055, transparent); margin: 25px 0;">

<h2 style="color: #ff0055; border-bottom: 2px solid #ff0055; padding-bottom: 8px; text-shadow: 0 0 5px #ff0055;">
  4. Perluasan Sistem "Escrow"
</h2>

<p style="color: #d1d1d1; line-height: 1.6;">
  Saat ini sistem escrow hanya berlaku untuk pembelian di dalam hub. Rencananya akan ditingkatkan menjadi platform transaksi aman yang lengkap antar pemain: <strong style="color: #ffffff;">mobil, akun, dan mata uang game</strong>. Transaksi langsung dalam game seluler sering kali memicu penipuan (scam), sehingga fitur ini menjadi solusi utama yang sangat dibutuhkan komunitas.
</p>
